# Employee Management System (EMS)

## Overview
A role-based Employee Management System built using Laravel REST API and jQuery frontend.

## Features
- Sanctum Authentication
- Role & Permission Management
- Employee CRUD Operations
- Department Management
- Pagination for users and employees
- Form Validation
- Protected Routes

## Tech Stack
- Laravel
- MySQL
- jQuery
- Bootstrap
- Sanctum Auth

## Installation

1. Clone repository
2. Run composer install
3. Configure .env
4. Run migrations
5. Start server

## API Endpoints
- POST /api/login
- POST /api/register
- GET /api/employees
- POST /api/employees
